## 5. 环境坑

**Python**：两个解释器，别混。

- ComfyUI：`C:\Users\LENOVO\Documents\New OpenCode Project\ComfyUI-master\venv\Scripts\python.exe`（torch 2.9.1+cu130）
- KI8 工具链：`D:\moss-image\KI8-1.4.0-rc1\KI8\.venv\Scripts\python.exe`（torch 2.9.1+cu128）

`run.py` 只能用后一个跑；ComfyUI 侧代码只能用前一个测。

**safetensors 段错误**：同一进程同时 `safe_open` 两个文件、或反复 open/close 会 access violation。用 `bench/st_read.py` 的 seek+read 实现。

**工作流 API 转换**：已保存的 UI 工作流早于 TE27B 节点新增的 `load_mode` / `device` widget，直接 `_ui_to_api` 会报 `not connected`。工作流里已补 `["dio","cuda"]`，安装器 `WIDGETS` 表也已同步。改节点签名时要同时改这两处。

**显存**：8 GB 卡可用 7.00 GiB。BF16 10.16 GB 进不来，基线只能 CPU。TE 和 DiT 不能同时驻留。

**网络**：Clash 在 `127.0.0.1:7897`，仅 HTTP(S) 转发可用；GitHub 上传走直连（约 2 MB/s），代理对大文件 PUT 会卡死。git push 需要 `-c http.proxy=http://127.0.0.1:7897`。gh CLI 上传单词约 5 MB/s 上限，多进程并行有效但要注意 `xargs -P` 会一次起满。

**磁盘**：D: 剩 16 GB，C: 剩 15 GB。权重分片和解包都占空间，动手前先看 `df -h`。
